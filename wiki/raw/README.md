# Raw Source Layer

This directory is reserved for immutable source artifacts that do not already have a canonical repository location: supplied reports, exported specifications, research snapshots, or other material intentionally ingested into the wiki.

Do not copy application code, schemas, manifests, or deployment files here. Their canonical locations are registered in [`../sources.md`](../sources.md), preventing stale duplicates. Never edit an imported raw artifact after ingest; add a new version and a new source-map entry instead.

No imported raw artifacts are currently stored here.
